# mirifici

A log-space number type for Rust. `Log<F>` stores a non-negative real number as its
natural logarithm, so multiplication becomes addition and values like 1e-5000 stay
representable.

Under construction. See [`docs/api.md`](docs/api.md) for the planned API.

Minimum supported Rust version: **1.85**.
